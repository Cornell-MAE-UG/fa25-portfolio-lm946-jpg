## MAE 2250: Open Design Project 3

### Project Overview
[cite_start]This project involved the design of an automated sorting system utilizing a conveyor belt, a roller with bristles for collection, and a pneumatic system involving compressed air and vacuum components [cite: 1-5, 7].

### System Components
* [cite_start]**Roller with Bristles:** Used to move material into the collector bin[cite: 1, 2].
* [cite_start]**Pneumatic System:** Utilizes compressed air and vacuum zones to sort materials into the trough[cite: 3, 4, 8].
* [cite_start]**Conveyor System:** Provides the primary movement for the sorting process[cite: 5, 7].
